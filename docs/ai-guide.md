# AI を使う場合のガイド

この授業では AI を使ってもかまいません。使わなくても授業は進められます。使う場合は、「AI が書いたコードを理解せずに動かす」のは危ない(GPIOを壊すことがある)ので、次のルールを守ってください。

## ルール

1. AI が書いたコードは、まず **読んで説明できる** ようにする。わからない行は AI に「この行は何をしているか」を聞く。
2. 第2回のコードは `dry_run()` で模擬実行してから、配線を確認してラズパイで動かす。
3. `lesson02/` 直下の教材は AI にも編集させない。`lesson02/excersises/` で作業する。
4. AI の出力をそのままレポートに貼らない。自分の言葉に直す。
5. 班の仲間にも、何を AI に頼んだか共有する(自分の練習コードのコメント に書く)。

## ツール別の始め方

AI ツールを使う場合は自分の PC で動かします(ラズパイ Zero 2 W はメモリが足りません)。できたコードは `git push` / `git pull` でラズパイに運びます。

### Claude Code

```
git clone -b group-a https://github.com/ishikuro-lab/seminar2.git
cd seminar2
claude
```

リポジトリの `CLAUDE.md` と `.claude/skills/` を自動で読みます。例:

- 「raspi-gpio スキルを読んで、LEDを3秒点灯するプログラムを lesson02/excersises/ に作って。with やクラスは使わないで」
- 「lesson02/01_led_on.py を1行ずつ説明して」

### Codex CLI / Gemini CLI / GitHub Copilot(VS Code)

同じく clone してリポジトリのフォルダで起動します。`AGENTS.md` を読みます。スキルを使いたいときは「.claude/skills/raspi-gpio/SKILL.md を読んでから」と頼んでください。

### ブラウザの ChatGPT / Gemini

ファイルの中身を貼り付けて質問します。最初に次の文を貼ると、授業のルールを踏まえた答えになります。

```
私は大学 1 年生で、Raspberry Pi Zero 2 W とブレッドボードで
LED とセンサの使い方を学んでいます。Python 3 を使います。
教材の lesson_gpio.py にある led_on、led_off、sleep、read_distance を使ってください。
with やクラスなどの難しい構文を避け、初心者向けに日本語で説明してください。
```

そのあとに `lesson02/01_led_on.py` の内容と、やりたいことを貼ります。

## 使えるプロンプトの例

| やりたいこと | 頼み方 |
|---|---|
| コードの理解 | 「このコードを 1 行ずつ日本語で説明して」 |
| 機能の追加 | 「01_led_on.py をもとに、LEDを2回点けるプログラムを書いて」 |
| エラーの解決 | エラー全文を貼って「このエラーの原因と直し方を教えて」 |
| テスト | 「このプログラムを安全に試す手順を順番に書いて」 |
| 振り返り | 「今日やったことを 3 行でまとめて、自分の練習コードのコメントに追記する文を作って」 |

## 気をつけること

- AI は配線やピン番号を間違えることがあります。`lesson02/README.md` の表と必ず照らし合わせる。
- `sudo` を使うコマンドを提案されたら、実行前に先生に確認する。
- パスワードやトークンを AI に貼らない。
