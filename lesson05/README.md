## フォトリフレクタのしくみ

赤外線を出す **発光素子** と、はね返った光を受ける **受光素子** が 1 組になった部品です。

- 白い床は光をよく反射する → 受光が多い → 出力は **1**
- 黒い線は光を吸う → 受光が少ない → 出力は **0**

センサ基板にはこれが 8 個、横一列に並んでいます(長さ 122 mm)。感度は基板の **VR(可変抵抗)** で 1 個ずつ調整できます。

## 配線(ロボット基板)

**配線は全部の電源を外してから** 行います。

| センサの端子 | GPIO | 基板の端子 |
|---|---|---|
| OUT1 | GPIO4 | J2-4 |
| OUT2 | GPIO27 | J2-7 |
| OUT3 | GPIO5 | J2-15 |
| OUT4 | GPIO6 | J2-16 |
| OUT5 | GPIO26 | J2-19 |
| OUT6 | GPIO25 | J3-11 |
| OUT7 | GPIO16 | J3-18 |
| OUT8 | GPIO20 | J3-19 |
| 5V(印字) | **+3V3 につなぐ** | J2-1 か J2-9 |
| GND | GND | J2-5 など |

- センサ基板の端子 CN1 には「5V」と印字されていますが、**3.3 V(+3V3)につなぎます**。ラズパイの GPIO は 3.3 V までだからです。
- 8 本全部使わなくてもかまいません。減らすときは、真ん中の OUT3〜OUT6 から使います。
- ほかの GPIO は、モーター(17・18・22・19)、サーボ(12)、LED(13)、超音波センサ(23・24)などに使っているので、上の表のピンを使います。

## 床との距離

- センサの面から床まで **5 mm 以内**(秋月の資料の推奨)。まず 2〜3 mm で試します。
- 高さを 1 mm ずつ変えて、白と黒がどちらも安定して読める範囲の真ん中にします。
- どの高さでも読めないときは、VR を回して感度を変えます。

## 実行のしかた

```sh
source ~/venv/bin/activate
cd ~/seminar2/students/$USER/lesson05/linesensor
python3 01_linesensor_read.py
```

1 秒ごとに、左に秒数、右に 8 個の 0 / 1(左から OUT1〜OUT8)が出ます。`Ctrl + C` で止めます。

```
Ctrl + C で止めます(白 = 1、黒 = 0)
  0 秒  [1, 1, 1, 1, 1, 1, 1, 1]
  1 秒  [1, 1, 1, 0, 0, 1, 1, 1]
```

センサを 1 個ずつ黒い線にかざして、その場所だけ 0 になるか、左右の順番が合っているかを確かめます。1 秒ごとに読むので、かざしたら 1 秒以上そのままにします。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 白なのに 0 のまま | 電源(+3V3)と GND の配線。床との距離が遠すぎないか。VR |
| 黒なのに 1 のまま | 床に近すぎないか、VR の感度が高すぎないか |
| 左右の順番が逆 | `sensor_pins` の並びを反対にする |
| `GPIO busy` | 前のプログラムが残っている。`ps aux \| grep python` → `kill 番号` |
| `ModuleNotFoundError: lgpio` | ラズパイ以外で実行している。ラズパイで実行する |
