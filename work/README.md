# work — 班の作業場所

班のコードや記録はここに置きます。`materials/` や `motor/` のファイルを使いたいときは、ここにコピーしてから編集してください(元を直すと教材の更新と衝突します)。

おすすめの置き方:

```
work/
  README.md        この班のメモ(担当、やったこと、次にやること)
  robot.py         走行プログラム
  test_motor.py    動作確認用
  notes/           測定メモや写真へのリンク(大きなファイルは置かない)
```

この README は自由に書き換えて、班のメモとして使ってください。
