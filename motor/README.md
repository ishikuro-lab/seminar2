# モーター動作確認

Raspberry Pi Zero 2 W と、矢上祭 2026 のロボット基板(モータードライバ DRV8833)で DC モーターを回す動作確認スクリプトです。

## 配線

基板のシルクと同じ割り当てです。DRV8833 の有効化ピンは基板上で 3.3V につながっているので、GPIO での操作は要りません。

| 側 | コネクタ | IN1 | IN2 |
|---|---|---|---|
| A | J4 | GPIO17(物理 11 番) | GPIO18(物理 12 番) |
| B | J5 | GPIO22(物理 15 番) | GPIO19(物理 35 番) |

片方のピンに PWM(1000 Hz)、もう片方を Low にすると回ります。IN1 に PWM を出す向きを「正転」と呼んでいます。

## 実行

**車輪を浮かせてから実行してください。** 基板のモーター電源スイッチも入れておきます。

```
cd ~/seminar2/motor
python3 motor_test.py
```

A 側、B 側の順に「正転 2 秒 → 停止 1 秒 → 逆転 2 秒 → 停止 1 秒」と動きます。途中で止めるときは `Ctrl + C` です。SSH が切れたときも、全ピンを Low にしてから終わります。

| オプション | 意味 |
|---|---|
| `--speed 0.6` | 出力を変える(0〜1、既定 0.4) |
| `--seconds 1` | 回す時間を変える(秒、既定 2) |
| `--motor A` | 片側だけ試す(`A` か `B`) |
| `--dry-run` | GPIO に触らず、出す値を表示するだけ |

## 直進

**床に置き、前方を空けてから実行してください。**

```
python3 straight.py
```

両輪を同時に回し、1 秒たつと自動で止まります。

| オプション | 意味 |
|---|---|
| `--speed 0.5` | 出力を変える(0〜1、既定 0.7) |
| `--seconds 2` | 走らせる時間を変える(秒、既定 1、上限 10) |
| `--flip A` | その側の向きを反転する(`A` か `B`)。向きを確かめるとき用 |
| `--dry-run` | GPIO に触らず、出す値を表示するだけ |

前進になる向きは `straight.py` の先頭の `FORWARD` で決めています。後ろに進む、その場で回るときは、`--flip` で試してから `FORWARD` を書き換えます。

## うまくいかないとき

- **回らない、うなるだけ**: 出力が足りていません。`--speed 0.6` のように上げてください。モーター電源のスイッチと電圧も確認します。
- **正転で後ろ向きに回る**: 向きはモーター線の差し方で決まります。コネクタの向きを逆にするか、コード側で正負を入れ替えます。
- **A 側と B 側が思った車輪と逆**: 基板の資料では J4(A 側)が右輪、J5(B 側)が左輪です。
- **`GPIO busy` と出る**: ほかのプログラムが同じピンを使っています。そのプログラムを止めてから実行します。

`lgpio` は Raspberry Pi OS に最初から入っています。入っていない場合は `sudo apt install python3-lgpio` で入れます。
