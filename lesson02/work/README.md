# 第2回の作業場所

班のコードや記録はここに置きます。`lesson02/` 直下の教材は変更せず、コピーして使ってください。

リポジトリのルートで準備します。

```bash
mkdir -p lesson02/work
cp -n lesson02/*.py lesson02/work/
cd lesson02/work
python3 01_led_on.py
```

`lesson_gpio.py` は教材と同じフォルダに置いてください。個人のフォルダで作業する場合も、一緒にコピーします。

```bash
# リポジトリのルートから実行
mkdir -p lesson02/work/taro
cp -n lesson02/*.py lesson02/work/taro/
```

班のメモには、担当・試したこと・次にやることを書きます。大きな測定ファイルや動画は置かないでください。

コピーの `-n` は、すでにある作業ファイルを上書きしない指定です。
