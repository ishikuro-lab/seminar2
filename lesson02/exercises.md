## 演習①: LED

### 1-1. SOS(`ex1_sos.py`)

モールス信号の SOS(短 3 回・長 3 回・短 3 回)を LED で表します。短 = 0.2 秒点灯、長 = 0.6 秒点灯、間は 0.2 秒消灯。1 回表示して終了します。

- ヒント: `02_led_blink.py` の `while True` を、`for` ループと関数に置き換える。「短く光る」「長く光る」を関数にすると読みやすい。

### 1-2. ピン番号を自分で決める(`ex1_pin_input.py`)

起動したら「GPIO 番号を入力してください:」と表示し、入力された番号の LED を 3 回点滅させます。配線も自分で変えます。

- ヒント: `pin = int(input("GPIO 番号を入力してください: "))`。モーター用(17, 18, 19, 22)は使わない。
- 発展: 番号が 2〜27 の範囲外なら「その番号は使えません」と表示して終了する。

### 1-3. 2 個の LED を交互に(`ex1_two_leds.py`)

LED を 2 個(例: GPIO12 と GPIO21)つなぎ、交互に点灯させます。間隔は `sleep()` に渡す数字で変えます。

- ヒント: `led_on(12)` と `led_on(21)`、それぞれの `led_off()` を使う。最後に使った LED を `led_off()` で消す。

### 1-4. 呼吸するように(`ex1_breath.py`、発展)

`04_led_fade.py` を改造して、明るくなるときはゆっくり(2 秒)、暗くなるときは速く(0.5 秒)にします。

- ヒント: 明るくする `for` と暗くする `for` で、`sleep()` の待ち時間を変える。

## 演習②: 超音波センサ

同じHC-SR04を複数人が同時に操作せず、実行は交代で行います。

### 2-1. 距離を測って記録する（`ex2_distance.py`）

`05_distance_read.py` をコピーして動かします。物を10 / 20 / 30 cmに置き、表示された値を班のメモに記録します。

### 2-2. 読む間隔を変える（`ex2_interval.py`）

`05_distance_read.py` の `sleep(0.2)` を `sleep(1)` に変え、表示の速さを比べます。

### 2-3. LEDが点く距離を変える（`ex2_near_led.py`）

`06_distance_led.py` の `distance < 10` を `distance < 20` に変え、点灯する距離を確認します。

### 2-4. 遠いときにLEDを点ける（`ex2_far_led.py`）

20 cmより遠いときにLEDが点くようにします。測れないときは消灯します。

- ヒント：`distance < 10` を `distance > 20` に変えます。`distance is None` の部分はそのまま使います。

`None` は「値がない」という意味です。測れなかった場合は距離を比較せず、LEDを消すようにしています。
